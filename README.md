# Future Gadget №2 PELMENI SCANER-AI ver1.048596 BETA

Это бета версия программы с искусственным интеллектом, которая может в реальном времени обрабатывать данные с RTSP камеры и выводить степень готовки пельменей. Эта программа позволяет удалённо следить за процессом варки пельменей и одновременно делать свои дела за компьютером/ноутбуком. Программа использует ResNet18 - сверточной нейронной сетью, которая применяется для классификации изображений и извлечения признаков. Пользователь за ранее собирает dataset из 3х видов фото: кипящая вода без пельменей, кипящие пельмени и нейтральная сцена, где пельмени в воде, но кипения ещё нет. 

Нейросеть обрабатывает изображения с RTSP камеры и сравнивает текущий кадр с изображением в папке. Если изображение с  RTSP камеры схоже на 80+% с тем, какое изображение в папке, то программа переходит на следующий этап. Программа проходит 4 этапа:
1) State Wath Water - Кипящая вода.
1.5) Задержка в 75 секунд для того, что бы пользователь смог успеть закинуть пельмени.
2) State Wath Pelmeni - Кипящие пельмени. Пельмени только что закипели.
3) State Wath Varka - Начинается процесс "варки" пельменей, который длиться 8 минут.
4) State Gotovo - На этом этапе пельмени уже должны быть готовы. Если ваши пельмени не готовы, увеличите переменную TIMER_MNIUTES (данные указываються в минутах) в коде pelmeni_scaner_server.py.

## ТЕХНИЧЕСКАЯ ИНФОРМАЦИЯ 
Backbone: torchvision.models.resnet18

Размер входного кадра: 224x224

Источник видео: RTSP-поток

Обработка: OpenCV

Проверка кадров: каждые 15 итераций

Порог уверенности: 0.80

Таймер варки: 8 минут

Устройство: CUDA при наличии GPU, иначе CPU

## УСТАНОВКА

1) Установить Python 3
2) Скачиваем архив и распаковываем в удобное место.
3) В командной строке или втерминале выполни:
    
    python -m pip install --upgrade pip
   
    python -m pip install torch torchvision opencv-python numpy

4) Внутри папки `dataset` (если нет то создаём нужные папки) должны быть три папки:

  - кипящая_вода

  - кипящие_пельмени

  - нейтральная_сцена

    *Имена папок менять нельзя. Они используются как имена классов.*

5) Положи в каждую папку изображения соответствующего состояния:

    - кипящая_вода - только кипящая вода без пельменей
    - кипящие_пельмени - кипящие пельмени
    - нейтральная_сцена - пельмени уже в кастрюле с водой, но вода ещё не кипит

    Чем больше разнообразных кадров, тем лучше будет обучение.

## ИСПОЛЬЗОВАНИЕ 
1. Открой терминал/консоль в папке проекта и выполни:

    `python train.py`

    После в этой папке должен появиться файл: pelmeni_model.pth

2. Открой файл pelmeni_scaner_server.py в любом редакторе и найди строку - RTSP_URL. Введи туда локальный адрес видео потока начинающиеся с rtsp://... 

    КОМПЬЮТЕР И КАМЕРА ДОЛЖНЫ НАХОДИТЬСЯ В ОДНОЙ СЕТИ!

3. Запусти RTSP-камеру и начни поток.

4. Запусти основную программу командой `python pelmeni_scaner_server.py`

Будет запущено окно с камерой и выводом состояния. Для закрытия программы нажми esc.
