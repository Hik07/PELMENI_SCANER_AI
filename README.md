# Future Gadget №2 PELMENI SCANER-AI ver1.048597 BETA (UPDATE: 24.10.2026)

Программа для мониторинга процесса варки пельменей в реальном времени с использованием компьютерного зрения. Гаджет подключается к RTSP-потоку с камеры (например, IP-камеры или стримингового приложения на телефоне), анализирует кадры через свёрточную нейронную сеть ResNet18 и управляет конечным автоматом состояний варки.

Разработано в Лаборатории Гаджетов Будущего. 

## Что нового в ver1.048597

- **Полноценный GUI**: Интерфейс перенесён на Tkinter. Камера отображается в Canvas, статусы и таймеры вынесены в боковую панель.
- **Динамическая конфигурация**: Адрес камеры и время варки задаются через интерфейс при запуске. Лезть в исходный код больше не нужно.
- **Стабильный Event Loop**: Полностью удалены блокирующие `time.sleep()` и `while True` из основного потока. Переподключение при обрыве связи происходит асинхронно, окно не перестаёт отвечать.
- **Исправление логики состояний**: Устранены ошибки сравнения строк (пробелы заменены на подчёркивания) и исправлен расчёт оставшегося времени (целочисленное деление вместо остатка).
- **Защита от спама**: Добавлен флаг блокировки повторного запуска, предотвращающий создание множественных потоков обработки кадров.

## Технические характеристики

- **Backbone**: `torchvision.models.resnet18`
- **Размер входного кадра**: 224x224
- **Источник видео**: RTSP-поток (OpenCV + FFmpeg backend)
- **Частота инференса**: 1 раз на каждые `CHECK_EVERY_N_FRAMES` кадров (по умолчанию 15) для экономии ресурсов GPU/CPU
- **Порог уверенности**: 0.80 (настраивается)
- **Устройство**: CUDA (при наличии), иначе CPU

3. Установи зависимости:

В корне появится файл pelmeni_model.pth.
  
## Использование

1. Запусти стриминг с камеры на телефоне или IP-камере.
2. Запусти основной скрипт:
   ```bash
   python pelmeni_scaner_server.py
3. В открывшемся окне введи корректный RTSP-адрес (должен начинаться с rtsp://) и укажи желаемое время варки в минутах.
4. Нажми кнопку "НАЧАТЬ СКАНИРОВАНИЕ ПЕЛЬМЕНЕЙ".
5. Программа автоматически пройдёт 4 этапа:
   - **State 1**: Ожидание кипения воды.
   - **State 2**: Пауза 75 секунд (время на закидывание пельменей).
   - **State 3**: Детекция кипения пельменей и запуск таймера обратного отсчёта.
   - **State 4**: Сигнал о готовности.

## Известные артефакты

Если в консоли появляются сообщения вида `[h264 @ ...] error while decoding MB ... bytestream`, не паникуй. Это штатные предупреждения декодера FFmpeg о потере макроблоков в RTSP-потоке из-за нестабильности сети. OpenCV автоматически пропускает битые кадры и продолжает работу. Это не влияет на точность детекции и не является признаком вмешательства группировки.
