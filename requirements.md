### Технические требования
ОС: проект использует кроссплатформенные библиотеки, поэтому должен работать на Windows, Linux и macOS при корректной установке зависимостей
 
Проверено на: Windows 10

Видеокарта: при наличии доступного CUDA проект использует GPU, иначе работает на CPU

Источник видео: RTSP-поток с телефона.

Запуск скриптов рекомендуется выполнять из корневой папки проекта
